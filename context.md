# Контекст проекта

Дата сохранения: 19 октября 2026 года.

## Цель проекта

MVP «Наставник по soft skills» на Blazor WebAssembly + ASP.NET Core Web API.

Основные направления:

- мини-курсы по soft skills и тайм-менеджменту;
- напоминания;
- мероприятия и лайфхаки (планируются);
- общение студентов и наставников;
- роли: пользователь/студент, наставник, администратор.

На текущем этапе реализованы регистрация, вход, профиль, выход и защита приватных маршрутов. Дизайн страниц намеренно минимальный: визуальную часть будет делать другой участник команды.

## Структура решения

- `BlazorApp` — Blazor WebAssembly клиент.
- `WorldSkillsAPI` — ASP.NET Core Web API.
- `WorldSkillsAPI.sln` — solution.
- PostgreSQL: база `WorldSkillsDB`, локальный порт `5432`.

Локальные адреса профилей HTTPS:

- Blazor: `https://localhost:7190`;
- API: `https://localhost:7244`;
- Swagger API: `https://localhost:7244/swagger`.

## Что сделано на клиенте

### Вход

Файл: `BlazorApp/Pages/Login.razor`.

- Маршрут `/login`.
- Поля логина и пароля.
- Вызов `ApiRequest.AuthUser`.
- Вывод сообщения API при ошибке.
- При успехе токен сохраняется через `AuthService`.
- Поддерживается параметр `returnUrl`: после входа пользователь возвращается на ранее запрошенную приватную страницу.

### Регистрация

Файл: `BlazorApp/Pages/Register.razor`.

- Маршрут `/register`.
- Поля имени, логина, пароля и подтверждения пароля.
- Проверка заполнения полей, длины пароля и совпадения паролей.
- Вызов `ApiRequest.RegUser`.
- После успешной регистрации выполняется переход на `/login`.

### Состояние авторизации

Файл: `BlazorApp/Services/AuthService.cs`.

- Токен сохраняется в `localStorage` под ключом `authToken`.
- `AuthService` наследует `AuthenticationStateProvider` и предоставляет состояние пользователя стандартному механизму авторизации Blazor.
- При восстановлении токена сервис проверяет сессию запросом `ApiRequest.Profile`.
- Вход обновляет состояние авторизации, а выход вызывает `ApiRequest.Logout`, очищает токен и уведомляет интерфейс.
- `AuthService` и `AuthenticationStateProvider` зарегистрированы как scoped-сервисы в `BlazorApp/Program.cs`.
- Подключён пакет `Microsoft.AspNetCore.Components.Authorization` версии `10.0.12`.

### Профиль и выход

Файл: `BlazorApp/Pages/Profile.razor`.

- Маршрут `/profile`.
- Страница защищена атрибутом `[Authorize]`.
- Имя и логин загружаются через `ApiRequest.Profile`.
- Выход доступен на странице профиля и в меню.
- После выхода пользователь перенаправляется на `/login`.

### Защита маршрутов

- `App.razor` использует `CascadingAuthenticationState` и `AuthorizeRouteView`.
- `RedirectToLogin.razor` перенаправляет неавторизованного пользователя на вход с `returnUrl`.
- Маршруты `/`, `/profile` и `/weather` защищены атрибутом `[Authorize]`.
- Меню через `AuthorizeView` показывает вход/регистрацию гостю и главную/профиль/выход авторизованному пользователю.

### Каталог курсов

Файл: `BlazorApp/Pages/Courses.razor`.

- Маршрут `/courses` защищён атрибутом `[Authorize]`.
- Курсы загружаются через существующий метод `ApiRequest.GetCourses()`.
- Выводятся название, описание и имя наставника.
- Обработаны состояния загрузки, пустого каталога и ошибки API с возможностью повторить запрос.
- В меню авторизованного пользователя добавлена ссылка «Курсы».

### Страница курса

Файл: `BlazorApp/Pages/CourseDetails.razor`.

- Защищённый маршрут `/courses/{id}`.
- Данные загружаются через `ApiRequest.GetCourse(id)`.
- Отображаются название, описание и наставник курса.
- Уроки выводятся по полю `position`.
- Обработаны загрузка, отсутствие уроков и ошибка API.
- В каталоге добавлен переход «Открыть курс».

### Страница урока

Файл: `BlazorApp/Pages/LessonDetails.razor`.

- Защищённый маршрут `/lessons/{id}`.
- Данные загружаются через `ApiRequest.GetLesson(id)`.
- Отображаются название и номер урока, название курса и содержание урока.
- Если у урока есть `videoUrl`, показывается безопасная внешняя ссылка на видео.
- Добавлен возврат к родительскому курсу.
- Уроки на странице курса стали ссылками.
- Обработаны загрузка и ошибка API.

### Прогресс обучения

- Страница урока загружает прогресс курса через `ApiRequest.GetCourseProgress` и определяет статус текущего урока.
- Отображаются состояния «Не начат», «В процессе» и «Завершён».
- Кнопка «Начать урок» вызывает `ApiRequest.StartLesson` и доступна только для неначатого урока.
- Кнопка «Завершить урок» вызывает `ApiRequest.CompleteLesson` и доступна только для урока в процессе.
- Клиент блокирует повторные действия; API отклоняет повторный запуск и повторное завершение урока.
- Страница курса показывает число завершённых уроков, общий процент и статус каждого урока.

## Изменения API

В `WorldSkillsAPI/Program.cs` добавлена CORS-политика для локального Blazor-клиента:

- `https://localhost:7190`;
- `http://localhost:5263`.

Без неё браузер блокирует запросы клиента к API на другом порту.

Текущий API сохраняет и сравнивает пароли в открытом виде. Для MVP тестовые данные соответствуют этому поведению, но перед реальным использованием необходимо добавить хеширование паролей.

## Тестовые данные

Создан повторно запускаемый PostgreSQL-скрипт:

`WorldSkillsAPI/Database/seed.sql`

Он добавляет:

- роли и справочники;
- наставников, студентов и администратора;
- 4 мини-курса;
- 10 уроков;
- практические задания;
- избранные курсы;
- прогресс;
- напоминания;
- сообщения в обсуждениях;
- пример ответа студента и оценки наставника.

Запуск из корня репозитория:

```bash
dotnet ef database update --project WorldSkillsAPI
psql -h localhost -p 5432 -U postgres -d WorldSkillsDB \
  -f WorldSkillsAPI/Database/seed.sql
```

Запуск из папки `WorldSkillsAPI`:

```bash
dotnet ef database update
psql -h localhost -p 5432 -U postgres -d WorldSkillsDB \
  -f Database/seed.sql
```

## Запуск проекта

Нужно одновременно запустить `WorldSkillsAPI` и `BlazorApp` с HTTPS-профилями.

На macOS Rider может показать ошибку:

`Default system browser option is not supported for Blazor apps. Please select a Chromium-based browser.`

Решение: в `Run → Edit Configurations` для `BlazorApp` выбрать Google Chrome, Microsoft Edge или другой Chromium-браузер. Альтернатива — установить `launchBrowser: false` в `BlazorApp/Properties/launchSettings.json` и открыть `https://localhost:7190` вручную.

## Проверки

- `WorldSkillsAPI` собирается без ошибок; в проекте есть существующие nullable-предупреждения.
- Blazor-клиент полностью собирается и запускается на `https://localhost:7190`.
- Реальный API-сценарий проверен: регистрация `200`, вход `200`, профиль `200`, выход `200`, запрос со старым токеном после выхода `401`.
- Созданный для проверки пользователь `qa-auth@student.local` после теста удалён из базы.
- SQL-скрипт тестовых данных создан и был запущен пользователем.

## Общая страница прогресса

Создана защищённая страница `BlazorApp/Pages/Progress.razor` с маршрутом `/progress`.

Страница использует существующие методы `ApiRequest.GetMyProgress()` и
`ApiRequest.GetCourses()`. На ней отображаются:

- количество уроков в процессе и завершённых уроков;
- группировка прогресса по курсам;
- название и текущий статус каждого начатого урока;
- даты начала и завершения;
- ссылки на страницы курса и урока;
- состояния загрузки, ошибки и отсутствия начатых уроков.

В меню авторизованного пользователя добавлена ссылка «Мой прогресс».
